**Issue snapshot limitations**

The initial `data/issues.json` contains real issue URLs retrieved through GitHub issue searches filtered to open issues on 2026-11-08. The repo and issue links were inspected in that search, but detailed eligibility, current assignment, latest linked PR status and suitability have NOT all been verified. It is a starting point, not a queue of guaranteed claimable issues. GitHub actions use live GitHub Search API queries and refresh these values only on successful runs. Search endpoint is documented at https://docs.github.com/en/rest/search/search#search-issues-and-pull-requests.

**Correction discipline**

If an organization does not participate in 2027, mark it inactive instead of deleting the historical evidence. If the 2027 calendar differs from 2026, update dates based only on the published timeline. Replace this reference file's historical links with the precise official 2027 guidance after announcement.
